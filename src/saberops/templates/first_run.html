3 · Discover models: listed vs executable

Listed means the vendor enumerates the model. Executable (SUPPORTED) means an exact binding resolved — only those may enter automatic routing. UNKNOWN stays out of auto-routing; unparseable output yields no IDs, never invented ones.

6 · Project setup

Plan registration rule

One active plan per project. A repo changed outside SaberOps forces re-verification before any wave starts; until then only single-job submit is offered, never a wave.

7 · Plan proposal → owner approval OWNER

What a proposal contains
  • Goal, constraints, and acceptance criteria
  • Ordered waves with lanes, each lane’s Touches list, and disjointness
  • Test-retirement table (kept or rewritten, with reason)
Unapproved plans are read-only. Proposals expire after 24 hours and must be re-proposed, never auto-extended. Approval happens here or via the CLI — never via chat or message.
