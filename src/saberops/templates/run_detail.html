Terminal

Read-only view of the supervised orch run (launched via a Linux PTY with argv only, no shell). The terminal shows what the CLI prints: worker/provider banner, model commentary, tool output, stdout/stderr, gate output, review/repair output, timeouts/errors, and final summary. No input is sent to the process. Reconnect replays the persisted ANSI transcript, then continues live. If the run is completed, the transcript remains available.
